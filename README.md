
# MAG CORE V08 — BLACK EDITION | FIELD_OS

**Le cœur tactique des systèmes intelligents.**

MAG CORE est un univers créatif, musical, cinématographique et technologique rétro-futuriste. C'est une architecture transmedia qui relie la musique, l'image, la vidéo, l'interface, la narration, l'architecture logicielle, l'IA et la mémoire.

## 🛠 Stack Technique
- **Framework** : Next.js 14 (App Router)
- **Langage** : TypeScript
- **Styling** : Tailwind CSS
- **3D** : React Three Fiber / Drei
- **Déploiement** : Vercel
